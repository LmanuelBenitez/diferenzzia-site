# Diferenzzia — Sitio oficial

Landing page informativa y de contacto para la banda **Diferenzzia**: rock alternativo, shows en vivo y booking.

## Stack

- **React 19** + **TypeScript**
- **Vite** (build tool)
- **Tailwind CSS** (estilos)
- **TanStack Query** (data fetching / caché)
- **react-hook-form** (formulario de booking)
- **axios** (cliente HTTP)
- **Netlify Functions** (proxy de Spotify y recepción de booking)

## Secciones

| Sección | Ancla | Descripción |
| --- | --- | --- |
| Hero | `#inicio` | Portada con nombre, género y CTA |
| Bio | `#bio` | Historia, datos e integrantes |
| Éxitos | `#top-tracks` | Top tracks desde la API de Spotify |
| Shows | `#shows` | Próximas fechas y sitios visitados |
| Booking | `#booking` | Formulario para agendar presentaciones |
| Contacto | `#contacto` | WhatsApp y redes sociales |
| Footer | — | Info general, links y redes |
